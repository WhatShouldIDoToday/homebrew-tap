# WhatShouldIDoToday Homebrew Tap

Homebrew formulae and casks for [WSID](https://github.com/WhatShouldIDoToday/WSID).

```sh
brew install WhatShouldIDoToday/tap/wsid
brew install WhatShouldIDoToday/tap/wsid-beta
brew install --cask WhatShouldIDoToday/tap/wsid-gui
brew install --cask WhatShouldIDoToday/tap/wsid-gui@beta
```

Formulae live in `Formula/` and casks in `Casks/`. Release automation updates them; do not edit by hand.
